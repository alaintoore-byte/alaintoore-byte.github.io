🔧 Setup Notes & Troubleshooting

Common issues and how to fix them

  • Download won't start: Check your internet connection. Try using a different browser (Chrome, Edge, or Firefox).
  • Installation fails: Make sure you are logged in as Administrator. Temporarily disable your antivirus and retry.
  • App doesn't open: Restart your PC. If the problem persists, reinstall the software.
  • Missing DLL error: Install the latest Microsoft Visual C++ Redistributable from Microsoft's website.
